# REV. FR. DR. JOSEPH RAJ — FINAL FRONTEND DEVELOPMENT PROMPT

## Professional Author, Theologian & Scholar Website

You are a senior UI/UX designer, visual designer, and frontend architect.

Design and develop a premium, professional, production-ready frontend for the official website of:

**Rev. Fr. Dr. Joseph Raj**

The website represents a priest, theologian, canonist, preacher, scholar, and author.

The website must communicate:

- Scholarly authority
- Spiritual depth
- Literary excellence
- Trust
- Professionalism
- Simplicity
- Timelessness
- Human warmth
- Editorial quality

The website should feel like the official digital presence of an established theologian and author.

It should NOT feel like:

- a SaaS website
- a startup landing page
- an AI product
- a gaming website
- a flashy portfolio
- a futuristic website
- a social-media profile
- a generic template

---

# 1. PRIMARY DESIGN DIRECTION

Use the design direction:

## "Premium Editorial + Scholarly + Timeless"

The visual language should be inspired by:

- prestigious academic institutions
- theological publications
- literary publishers
- university faculty websites
- premium author websites
- scholarly journals
- classical editorial design

The design should remain visually relevant for many years.

Do not follow temporary web-design trends simply because they are popular.

The website should look premium because of:

- typography
- spacing
- composition
- color harmony
- grid
- imagery
- book-cover presentation
- hierarchy
- content structure

NOT because of visual effects.

---

# 2. ABSOLUTE DESIGN RESTRICTIONS

Do NOT use:

- Glassmorphism
- Backdrop blur UI
- Motion graphics
- Parallax scrolling
- WebGL
- WebGL shaders
- Particle systems
- 3D effects
- Animated backgrounds
- Animated gradients
- Scroll-triggered animations
- Large entrance animations
- Lottie animations
- GSAP
- Framer Motion
- SVG animations
- Shimmer loading animations
- Pulsing skeleton animations
- Glowing effects
- Neon colors
- Excessive gradients
- Floating glass cards
- Excessive rounded cards
- Excessive drop shadows
- Flashy page transitions
- Image zoom animations
- Excessive hover animations

The website must remain calm, elegant and professional.

---

# 3. ALLOWED INTERACTIONS

Use only subtle functional interactions.

Allowed:

- navigation hover state
- active navigation state
- subtle link underline
- subtle button hover
- button focus state
- form validation states
- form loading state
- form success state
- form error state
- mobile menu open/close
- subtle border/color changes
- accessible keyboard focus

Interactions must be immediate and restrained.

Do not use animation merely to make the website look impressive.

---

# 4. IMAGE LOADING EXPERIENCE

Image loading may use a **static blurred or gradient placeholder**.

For example:

Image request
↓
Static blurred/low-resolution placeholder
↓
Final image

Do NOT use:

- shimmer
- animated skeleton
- pulsing gradient
- animated blur
- moving placeholder

The loading experience should feel calm and professional.

Use `next/image` in the eventual Next.js implementation.

---

# 5. BRAND PERSONALITY

The website should communicate five primary qualities:

### SCHOLARLY

Strong typography and structured information.

### SPIRITUAL

Calm colors and generous whitespace.

### LITERARY

Elegant serif typography and carefully presented books.

### PROFESSIONAL

Clear information architecture and navigation.

### TIMELESS

No dependency on visual trends.

---

# 7. COLOR PRINCIPLE

The website should approximately follow:

70% neutral / ivory / white

20% deep navy

10% accent and supporting colors

Do not introduce random colors.

Every color should have a defined purpose.

Maintain WCAG-conscious contrast.

---

# 8. TYPOGRAPHY SYSTEM

Typography is one of the most important aspects of the website.

Use a sophisticated:

## SERIF + SANS-SERIF

system.

---

## DISPLAY / HEADINGS

Use ONE elegant editorial serif family.

Possible choices:

- Cormorant Garamond
- EB Garamond
- Libre Baskerville
- Source Serif
- Playfair Display

Choose the most appropriate one.

Do not mix multiple decorative serif fonts.

The heading font should communicate:

- scholarship
- literature
- authority
- tradition

---

## BODY

Use ONE clean modern sans-serif.

Possible choices:

- Inter
- Source Sans 3
- Manrope
- IBM Plex Sans

Choose ONE.

The body font must prioritize readability.

---

# 9. TYPOGRAPHIC HIERARCHY

Create a complete typography system:

- Display
- H1
- H2
- H3
- H4
- Body Large
- Body
- Body Small
- Caption
- Navigation
- Button
- Metadata
- Book Title
- Eyebrow

Use typography and spacing to create hierarchy.

Do not rely on boxes and shadows to create hierarchy.

---

# 10. LAYOUT

Use a professional editorial grid.

Maximum desktop content width:

Approximately 1200–1280px.

Use:

- generous whitespace
- consistent gutters
- strong alignment
- clear columns
- balanced proportions

Do not overcrowd the page.

Whitespace is a major design element.

---

# 11. RESPONSIVE BREAKPOINTS

Design and test:

- 1440px
- 1280px
- 1024px
- 768px
- 390px
- 375px

Mobile must be intentionally designed.

Do not simply shrink the desktop layout.

# 13. MOBILE NAVIGATION
