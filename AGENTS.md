# Joseph Raj Website

This is a standard Vite + React + Tailwind website project.

## Local development

- Install dependencies with `npm install` or `pnpm install`
- Start the app with `npm run dev`
- Build the production bundle with `npm run build`

## Project structure

- `src/main.tsx` - app entry point
- `src/App.tsx` - main application component
- `src/index.css` - global styles and Tailwind import
- `vite.config.ts` - Vite configuration
- `index.html` - HTML shell

## Notes

- Keep the codebase free of Figma or design-tool specific scaffolding
- Use standard React and Vite conventions
- Prefer direct Tailwind utility classes in JSX
